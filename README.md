# 像素工坊 · Pixel Foundry

**把图片和视频转换成游戏用像素风素材。**

Windows 64 位桌面工具，素材在本机处理，无需安装 Node.js 或启动服务器。

[下载与版本发布](https://github.com/luochenmuxi-sys/pixel-foundry-releases/releases) · [反馈问题](https://github.com/luochenmuxi-sys/pixel-foundry-releases/issues)

---

## 有什么功能？

| 功能 | 能做什么 |
| --- | --- |
| 🖼️ 图片像素化 | 调整像素尺寸，使用主色采样或最近邻，让每格使用一个实色。 |
| 🎨 调色与限色 | 自动提取色板，支持 PICO-8、掌机、灰阶、自定义颜色，以及抖色、亮度和对比度调整。 |
| ✂️ 背景剔除 | 原图取色、识别边缘背景、同时剔除多种背景色，支持容差和边缘连通保护。 |
| 📐 边缘裁剪 | 自动裁掉透明空边，或在原图框选、输入裁剪位置与尺寸。 |
| ✏️ 像素修补 | 画笔、橡皮、吸色、网格预览、撤销和重做。 |
| 📦 PNG 导出 | 保留透明背景；1×直接保存逻辑像素，2× / 4× / 8×使用整数倍复制。 |
| 🎬 视频像素化 | 选择片段、帧率、像素宽度和倍率，逐帧转换，整段固定色板。 |
| 💾 保存工程 | 保存原图、背景色、裁剪参数、色板和手绘修补，方便继续编辑。 |

## 怎么使用？

**图片：** 导入图片 → 设置像素宽度与色板 → 去背景 / 裁边 → 修补细节 → 导出 PNG。

角色和道具可先尝试 **48 / 64 像素宽、8–16 色**。1×图片本来就很小，检查细节时建议使用软件内的整数倍预览。

**视频：** 顶部选择「视频像素化」→ 导入视频 → 载入首帧调整风格 → 返回视频页 → 转换并导出。

**安装：** 安装版适合长期使用；便携 EXE 双击运行。安装包统一放在本仓库的 Releases 中。

## 联网更新

正在为安装版接入以下流程：

1. 启动时或手动检查新版本。
2. 查看新版本提示，下载更新并显示进度。
3. 完成校验后，由用户确认重启安装。

更新保留应用设置和已导出的素材，重启前请先保存工程。已使用初版 **1.0.0** 的用户，需要先手动安装一次带更新功能的新版本；便携版通过发布页下载新版。

## 当前使用范围

- 视频目前为**无声导出**，单次片段最多 **60 秒**，根据编码能力输出 MP4 或 WebM。
- 视频编码有损；需要精确颜色和透明通道的游戏图片素材，请导出 PNG。
- 自动像素化提供整格取色、限色和色块归并，具体人物造型和明暗仍可用画笔修整。
- 工程不嵌入原视频，重新打开后需要再次选择视频文件。
- 安装包暂未配置 Windows 发布者数字签名。

素材处理不上传图片或视频。联网更新将访问本仓库的发布地址。本仓库用于分发安装包和说明，不包含用户测试素材。
